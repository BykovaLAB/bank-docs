# Настройка аккаунта  

Перед началом работы в приложении Nova Bank необходимо заполнить данные вашего профиля.

Чтобы начать настройку, нажмите на иконку своего профиля в главном меню приложения.

1. Введите электроную почту и нажмите на кнопку **Далее**.  

<img src="../img/Account Set Up Email.png" alt="Ввод электронной почты" width="200">  

2. Выберите подходящий тип учётной записи из выпадающего списка: «Личный» или «Бизнес». Нажмите на кнопку **Далее**.
<img src="../img/Account Set Up Email (1).png" alt="Выбор типа учетной записи" width="200">  

3. Добавьте адрес регистрации (поле можно пропустить): 
- Укажите город или регион.
- Укажите почтовый индекс.  
- Введите ваш адрес.

Нажмите на кнопку **Далее**. 

<img src="../img/Account Set Up Address.png" alt="Данные адреса регистрации" width="200">  

4. Добавьте личные данные:  
- Введите полное имя.
- Укажите дату рождения (необязательное поле).   
Выберите дату в календаре и нажмите **Далее** в окне выбора.  

Затем нажмите основную кнопку **Далее** внизу экрана, чтобы перейти к следующему шагу.

<img src="../img/Account Set Up Personal Info 3.png" alt="Личные данные" width="200"> <img src="../img/Account Set Up Personal Info 4.png" alt="date picker" width="200">  

После завершения настройки откроется раздел **Профиль** с обновлёнными данными.
