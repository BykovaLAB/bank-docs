# Настройка аккаунта  

Для настройки аккаунта выполните следующие шаги:

1. Введите электроную почту и нажмите на кнопку **Далее**.  

src="../img/Account Set Up Email.png" alt="Ввод электронной почты" width="200">  

2. Выберите тип учетной записи и нажмите на кнопку **Далее**.

src="../img/Account Set Up Email (1).png" alt="Выбор типа учетной записи" width="200">  

3. Добавьте данные адреса регистрации, заполнив обязательные поля: 
- Введите ваш адрес.
- Укажите город или регион.
- Укажите почтовый индекс.  

Нажмите на кнопку **Далее**. 

src="../img/Account Set Up Address.png" alt="Данные адреса регистрации" width="200">  

4. Добавьте личные данные:  
- Введите полное имя.
- Для даты рождения используйте календарь (date picker): нажмите на поле и выберите день, месяц и год рождения, затем **Далее**.

Нажмите на кнопку **Далее**.
